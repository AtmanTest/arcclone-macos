# ArcClone

A macOS multi-window web browser inspired by Arc Browser.

## Features

- Split-view columns with independent WKWebView navigation
- Left sidebar with Spaces, folders, and pinned tabs
- Bookmark import from Safari/Chrome
- Core Data persistence
- Keyboard shortcuts (Cmd+D new column, Cmd+W close, Cmd+S toggle sidebar)

## Build

```bash
open ArcClone.xcodeproj
# Select target > Build (Cmd+B)
```

## Requirements

- macOS 14.0+
- Xcode 16+
